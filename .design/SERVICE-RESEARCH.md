## 구현

- 3단계 제작 화면: 기록 기간 및 실제 기록 미리보기 → 부모 메시지 → 선택 주제 및 제작 요약.
- 입력 검증, 이전 단계 이동, 마지막 단계에서만 제작 버튼 제공. 메시지 오류 시 입력 위치로 이동.
- PC: 입력 + 고정 요약. 좁은 화면: 입력 우선, 마지막 단계에 요약과 제작 버튼.
- 일기: 저장 패널을 꾸미기보다 먼저 제공. 질문으로 글쓰기를 돕고 꾸미기는 선택적으로 펼침.
- 저장된 일기에서 그 날짜를 담은 동화 제작으로 바로 연결.
- 표지 예시와 실제 결과의 차이, 체험 모드의 브라우저 저장을 설명.
- 기존 NomadKit Sand / Ocean / Forest 역할 유지. 고운돋움 제목·기록, Pretendard 조작 요소, 고운바탕 책 본문.

## 범위

해당 서비스의 신뢰 표시는 그 서비스에만 해당한다. 하루동화에 고객 수, 후기, 수상, 암호화, 인쇄·배송, 결제 기능을 임의로 추가하지 않았다. 폰트 라이선스는 public/licenses/ 참고.


## 검증

- TypeScript + Vite 프로덕션 빌드 및 oxlint 통과. Vite의 500kB 번들 크기 경고는 남아 있음.
- 브라우저에서 제작 1 → 2 → 3 이동, 빈 메시지 차단 및 입력 포커스, 최종 메시지 요약 확인.
- 기록 화면의 빈 저장 차단, 입력칸 옆 오류 표시 및 포커스 확인.
- 390 × 844 모바일과 데스크톱에서 기록 화면·제작 확인 화면 검수. 모바일 뷰포트 설정은 검수 후 복원.
- 실제 기록 저장 및 동화 생성 요청은 이번 검수에서 실행하지 않음.
